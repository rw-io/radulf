Retrying a pull-request delivery now adopts the PR an earlier attempt already opened instead of failing on a second `gh pr create`. `src/server/github.ts` gains `findOpenPullRequest` (`gh pr list --head … --base … --state open --json url,isDraft --limit 1`), and `deliverPullRequest` calls it after the push: when an open PR exists it skips `gh pr create` and completes the approval with `prUrl`, `draft` taken from the PR's `isDraft`, and `alreadyOpen: true`; when the lookup fails or finds nothing it proceeds to `gh pr create` exactly as before and never falls toward a local merge. Covered by three new `github.test.ts` cases (one-element array, empty array, non-zero exit) and three new `reviewService.pr.test.ts` cases (adopt existing PR, lookup failure still creates, `retryMerge` from Needs Attention lands in Done).
